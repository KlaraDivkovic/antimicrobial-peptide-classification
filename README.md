# Klasifikacija antimikrobnih peptida

Cilj projekta je razlikovati antimikrobne peptide od neantimikrobnih pomoću metoda strojnog učenja.

Projekt se sastoji od četiri dijela:

1. Priprema podataka
2. Ekstrakcija značajki
3. Izrada modela
4. Evaluacija modela

Korištene tehnologije:
- Python
- Pandas
- BioPython
- Scikit-learn
- Matplotlib

Modeli:
- Random Forest
- SVM
